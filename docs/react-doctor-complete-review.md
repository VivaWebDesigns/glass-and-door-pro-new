## Changes and compatibility

- Sanitize CMS/public-form markup; script tags, event handlers, unsafe URLs and iframe srcdoc are removed. Custom executable HTML is intentionally no longer supported at these sinks. HTTPS raw embeds run in a restricted sandbox; inline presentation markup remains supported.
- Require explicit SESSION_SECRET for encrypted settings. Existing values encrypted with the configured key stay compatible. Local data encrypted with the previous implicit development key requires that same key to be explicitly configured or the secrets to be re-entered. No database data/schema was changed.
- Validate document writes, derive selected docs from query data, isolate editor sessions, stabilize editable-row identity/context providers, cancel abandoned crop requests, fix field-selection semantics, and clear ESLint findings.
- Format every source file in the project's formatting scope. Update compatible dependencies and browser data. Split the vendor bundle into runtime/UI/general groups; largest client chunk fell from approximately 695 kB to 402 kB.
